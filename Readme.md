# 🌍 Reto 2: Creación de una página web básica con HTML

Este proyecto corresponde a la resolución del **Reto 2**, cuyo objetivo principal es diseñar y estructurar una página web utilizando exclusivamente etiquetas y atributos fundamentales de **HTML5**.

Para este ejercicio, elegí como temática **El Planeta Tierra**, detallando su introducción, datos curiosos, atmósfera, océanos y continentes.

---

## 🛠️ Requisitos del Reto Cumplidos

El proyecto integra de manera estricta todos los elementos solicitados en la guía:

*   **Encabezado:** Uso de etiquetas `<header>`, `<h1>` para el título principal y `<h3>` para secciones.
*   **Párrafos:** Textos descriptivos enriquecidos con estilos de énfasis (`<strong>` y `<em>`).
*   **Imágenes:** Inclusión de imágenes ilustrativas del planeta con sus respectivos atributos `alt`, `width` y `height`.
*   **Enlaces:** Creación de un menú de navegación interno (índice) y enlaces externos a fuentes oficiales (NASA y Wikipedia).
*   **Listas:** Uso de listas no ordenadas (`<ul>`) para datos y listas ordenadas (`<ol>`) para clasificaciones de tamaño.

---

## 💻 Etiquetas HTML Aprendidas y Aplicadas

Durante el desarrollo de este reto se pusieron en práctica los siguientes comandos y rótulos esenciales:

*   `<!DOCTYPE html>`: Declara el tipo de documento y la versión de HTML.
*   `<html lang="es">`: Elemento raíz de la página web con el idioma especificado en español.
*   `<meta charset="UTF-8">`: Especifica la codificación de caracteres para la correcta visualización de tildes y caracteres especiales.
*   `<img>`: Incorpora imágenes mediante el atributo `src` y descripciones alternativas con `alt`.
*   `<ul>` y `<ol>`: Definición de listas no ordenadas y ordenadas respectivamente.
*   `<li>`: Define cada uno de los ítems de las listas.
